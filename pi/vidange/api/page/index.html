Cartes ESP32 (FluidNC) et accéléromètre

Envoyer un programme au Pi

Pour une carte ESP32 : le fichier « firmware.bin » d'une version de FluidNC, renommé avec sa version (exemple : « fluidnc-3.9.5.bin »). Pour l'accéléromètre : le fichier « accelerometre.bin » fabriqué par GitHub. Il est seulement gardé sur le Pi : on choisit ensuite où l'écrire.
