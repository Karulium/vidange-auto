Vidange automatique : il faut créer le premier compte

La page est fermée tant qu'il n'y a aucun compte. Pour en créer un, il faut être devant le Pi (ou y entrer par SSH). Taper cette commande, puis un mot de passe d'au moins 10 caractères :

sudo -u vidange /opt/vidange-auto/pi/.venv/bin/vidange compte ajouter moi --role karulium

Remplacer moi par le nom voulu. Les trois rôles :

  • karulium : tous les droits (regarder, produire, régler) ;
  • employe : regarder et produire (Go, lots, boutons de production), sans réglages ;
  • visiteur : regarder seulement.

Ensuite, recharger cette page : le formulaire de connexion apparaît (pas besoin de redémarrer le programme). Pas à pas : pi/systeme/essai-comptes.md.
