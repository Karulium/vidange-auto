# vidange-auto

Logiciel de la machine « Vidange automatique » de Karulium.

- `CLAUDE.md` : les consignes que suit chaque session Claude.
- `docs/architecture.md` : comment le logiciel est découpé.
- `docs/decisions.md` : les décisions déjà prises qui touchent le code.
- `docs/taches.md` : la liste des tâches, dans l'ordre, avec la phrase à donner à chaque session.
- `pi/` : programme du Raspberry Pi 5 (le chef).
- `fluidnc/` : réglages des cartes ESP32 FluidNC (axes).
- `spray/` : programme de la carte ESP32 du spray.
- `accelerometre/` : programme du RP2040 qui détecte les chocs.
- `nextion/` : pages de l'écran Nextion de l'armoire.
